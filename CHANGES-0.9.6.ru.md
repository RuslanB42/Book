# 0.9.6
- Переход по вкладкам: уходящая страница — настоящая, а не снимок (тени и вид не меняются в первый кадр); новая страница едет целиком вместе с верхними кнопками; прокрутка вкладки восстанавливается до первого кадра — кнопки сверху больше не мигают.
- «＋»: кнопки меню получают начальное положение до первого кадра (без вспышки), выезжают из кнопки плавно, без пружинного дрожания; закрытие короче и мягче.
