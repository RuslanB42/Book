# Polka Native 0.6.31

- Плашка «Дни подряд»: сокращённые названия дней недели теперь строго по центру под своими кружками (раньше прижимались к левому краю колонки).
- Плашка «Цель на год»: убрана метрика «до плана» и отметка «по плану». Показывается понятное «N из M», шкала прогресса и подпись «Осталось: K книг» (или «Цель достигнута!»).
