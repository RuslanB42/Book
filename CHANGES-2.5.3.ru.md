# Glyph 2.5.3

- Окно ввода названия: клавиатура закрывается первой, окно уезжает вместе с ней, клавиатура больше не висит над страницей.
- Библиотека больше не сдвигается и не перестраивается, когда клавиатура открывается или закрывается в окне поверх неё.
- Удаление полки из быстрого меню: полка плавно уезжает, промежуток закрывается, страница не перестраивается целиком.
- Над полкой больше нет затемнения стены, которое лежало слоями.
