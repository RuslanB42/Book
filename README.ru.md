# Polka · Android Native 0.6.15

Основной целевой телефон — Samsung Galaxy S22. Изменения: CHANGES-0.6.15.ru.md; проверки: TESTING.ru.md; аудит: PARITY.ru.md.

Kotlin + Android Views + Room / SQLite. Без WebView и браузерного хранилища. Android 8.0+.

## Обновление с предыдущих версий

Сохраните внешнюю копию `.polka` через Профиль → Настройки. Установите APK поверх существующего приложения: тот же applicationId, тот же сертификат, versionCode увеличен до 25. Удалять прежнюю версию или очищать его данные не нужно. Если Android сообщает о несовпадении подписи, не удаляйте приложение: сначала сохраните внешнюю копию.

## Перенос из веб-версии

В веб-приложении сохраните `.polka`, в Android откройте Профиль → Настройки → Восстановить из файла. Проверьте восстановленную библиотеку, затем создайте внешнюю копию уже из Android. Синхронизации между двумя приложениями нет.

## Важно

Требование абсолютного визуального и функционального паритета пока НЕ выполнено. Этот проект и APK — промежуточный результат, не финальная замена веб-версии. Известные расхождения перечислены ниже и в отчёте изменений.

См. `CHANGES-0.6.6.ru.md` — нижняя навигация, свайпы и живой поиск; `CHANGES-0.6.5.ru.md` — исправление рамок и настоящий edge-to-edge; `CHANGES-0.6.4.ru.md` — удержание/перенос книг и общие безопасные зоны; `CHANGES-0.6.3.ru.md` — читалка, полноэкранный режим и блокнот; `CHANGES-0.6.1.ru.md` — стеклянные полки; `CHANGES-0.6.ru.md` — предыдущие изменения и ограничения. Импорт отдельного файла и распакованной книги ограничен 128 МБ; JSON-записи резервной копии — 64 МБ. Восстановление требует места под текущую библиотеку, временную базу и защитную копию.

## Хранение и защита данных

- База `polka.sqlite` — приватная база приложения Room / SQLite в постоянном хранилище приложения, не cache. WAL, `synchronous=FULL`, транзакционные изменения и контроль количества книг.
- Тексты и двоичные файлы хранятся частями до 512 КБ, чтобы не упираться в ограничение SQLite CursorWindow на больших EPUB/обложках.
- Нет `fallbackToDestructiveMigration`, автоматического сброса базы или заполнения пустой библиотеки демонстрационными книгами.
- При импорте и восстановлении проверяются структура, ссылки на файлы и SHA-256 контрольные суммы. Новая библиотека собирается во временной базе, и только после проверки текущая заменяется одной транзакцией.
- После изменений сохраняются «Последняя» и «Предыдущая» локальные точки; перед удалением книги/восстановлением — «Перед изменением». Неудачная копия не заменяет предыдущую.
- Очистка данных приложения, удаление приложения, потеря телефона или сбой накопителя могут удалить и базу, и локальные точки. Внешняя копия `.polka`, хранящаяся отдельно, всё равно необходима. Автоматической облачной синхронизации нет. Резервные файлы не зашифрованы.
- Приложение не запрашивает доступ ко всем файлам и работает с выбранными документами через Android Storage Access Framework. Разрешение на интернет не требуется.

## Сборка и обновления

Откройте папку в Android Studio с JDK 17 и Android SDK 35. Либо:

```sh
./gradlew assembleDebug
./gradlew testDebugUnitTest lintDebug
```

Gradle Wrapper 8.9 включён. Первая сборка скачает Gradle, плагины и зависимости. APK: `app/build/outputs/apk/debug/app-debug.apk`. В `local.properties` при необходимости укажите путь к своему SDK; файл с путём компьютера сборки не включён в архив.

Идентификатор приложения: `app.polka.nativeapp`.

Закрытый ключ подписи **не включён в этот архив**. Приложенный APK подписан прежним локальным ключом, чтобы сохранялась возможность обновления поверх предыдущих версий. Для самостоятельной сборки обновления требуется тот же ключ в `signing/polka-local.keystore`; сохраните его из своей исходной среды сборки отдельно и не публикуйте. Конфигурация Gradle ожидает этот файл. Новый ключ или обычный debug-keystore создаст несовместимую подпись: такую APK нельзя устанавливать поверх прежней версии. Не удаляйте приложение ради установки — сначала сохраните внешнюю .polka. Для Google Play нужен отдельный процесс релизной подписи.
