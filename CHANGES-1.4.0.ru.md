# Полка 1.4.0

- Новые уведомления (утверждённый вариант «А»): карточка сверху с обложкой книги, знак результата перед заголовком, одна кнопка там, где есть следующий шаг.
- Знак всегда честный: крутится, пока идёт работа; галочка — только при успехе; «!» — если добавилось не всё; крестик — при ошибке.
- Все случаи: книга добавлена, несколько книг, добавлено не всё («Подробнее»), не добавлена («Подробнее»), уже в библиотеке («Открыть»), файл прикреплён, книга удалена («Вернуть» — 5 секунд на отмену).
- Анимации: мягкое появление сверху с пружиной, свет бежит по пустой обложке и прогресс по низу при загрузке, обложка проявляется и знак рисуется при результате, текст и размер меняются плавно, ошибка — короткое покачивание; уведомление можно смахнуть вверх.
- Системные уведомления Android («Цитата скопирована», «Полка уже есть», «Выделение ограничено главой») заменены компактной плашкой в том же стиле.
