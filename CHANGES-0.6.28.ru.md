# Polka Native 0.6.28 — новая страница статистики и исправление клавиатуры

## Клавиатура в окнах ввода
Окна-листы (цель на год, заметка, данные книги, ввод в диалогах) строились на AlertDialog без собственного поля ввода. Android в таком случае помечает окно флагом ALT_FOCUSABLE_IM, и окно не могло подключиться к клавиатуре — она открывалась «как повезёт». Флаг снят для всех листов; в окнах с одним–двумя полями курсор ставится в первое поле и клавиатура открывается сама, как только окно получило фокус. В длинных формах (данные книги) клавиатура открывается по нажатию на поле.

## Статистика
- Тихий серый фон, белые и пастельные карточки с крупным радиусом, крупные числа, мелкие серые подписи.
- Неделя — ряд белых плашек: тёмный кружок с галочкой, если цель дня выполнена; коралловый — сегодня; серый — пусто; точка — было чтение. Сегодня обведено.
- «Дни подряд» — мягкая зелёная карточка с прежним огоньком, подписью и меткой цели дня.
- Годовая цель: переключатель-таблетка, круглое кольцо с процентом и тёмная кнопка.
- «Прочитано книг» и «Скорость чтения» — две пастельные плитки; скорость — тонкие штрихи.
- «Время чтения» — тонкие столбики, выбранный (или последний) столбик тёмный, подписи по краям оси.
- «Любимый автор» — тёплая карточка с обложками.
- Содержание и поведение прежние: без заголовка страницы, те же метрики, период Месяц/Год/Всё время, календарь, цель.
