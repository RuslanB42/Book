# Polka Native 0.6.26 — огонёк, возврат обложки и новый знак

- В карточку серии чтения возвращён прежний трёхслойный градиентный FlameView с числом серии. Solar Pop и реальные недельные отметки сохранены.
- Из окна подробностей убрана видимая надпись «О книге». Кнопки закрытия, меню и маркер жеста сохранены; название окна для доступности остаётся.
- Общая обложка рисуется в отдельном корневом проходе поверх окна. Убрана ограниченная saveLayer/RenderNode-композиция трансформированного дочернего View, которая могла обрезать карточку при закрытии. Верхнее тонирование накладывается непосредственно внутри контура обложки без промежуточного слоя. Плавное затухание содержимого к верху окна сохранено.
- При возврате обложки исходный View скрыт до конечного кадра, затем возвращается вместе с удалением анимационного окна. Проверяются возвраты и в сетку, и в «Продолжить чтение».
- Значок приложения переработан по референсу книг на полке: графитовый фон, светлый металлический рельеф, детали корешков. Адаптивная и монохромная версии сохранены.
- Экран загрузки библиотеки показывает тот же знак вместо надписи «Полка». Для Android 12+ задан системный splash, для старых Android — стартовый фон со знаком.

Программные проверки не заменяют проверку закрытия на физическом телефоне/GPU. Устанавливать поверх предыдущей версии без удаления приложения. Подпись и appId прежние; миграций данных нет. Резервная копия .polka рекомендуется.
