# 0.9.5
- Обложка, летящая с полки в карточку и обратно, больше не разрезается полосой посередине: «за стеклом» она только в своём гнезде и плавно выходит вперёд, как только поднимается с полки.
- Обложки больше не моргают чужой заглушкой при входе в полку: пока картинка грузится — тихая пустая обложка, затем картинка плавно проявляется. Кэш обложек больше, чтобы их реже приходилось грузить заново.
