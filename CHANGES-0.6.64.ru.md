# 0.6.64

- Открытие книги начинается сразу по тапу (раньше была пауза на подготовку текста); пока текст готовится, книга мягко «зависает» на спокойной точке полёта и продолжает без рывка.
- Объёмная книга: освещение обложки по углу раскрытия (темнеет к ребру), блик, скользящий по обложке, канавка-шарнир у корешка, внутренняя сторона светлеет к читателю, торцы обложки темнее ткани.
- Без выделения памяти на каждом кадре (градиенты кэшируются).
- Перелистывание: тень от поднятого листа, скорость после отпускания сохраняется, снимок страницы переиспользуется.
