# 1.0.3
- Статистика: фон — тот же ровный тёмный, что во всём приложении (без светлого градиента), карточки плотные тёмные с едва заметной кромкой — серость ушла.
- Огонёк при раскрытом календаре больше не размывается.
- Свечение выбранного столбика — один мягкий круглый ореол вместо слоёных рамок.
- Анимации спокойнее и короче: карточки — быстрый подъём волной без пружинного перелёта, цифры — 0,65 с, столбики вырастают за полсекунды, книги в стопке ложатся без отскока, огонёк и обложки почти неподвижны; страница «Все книги» въезжает без отскока.
