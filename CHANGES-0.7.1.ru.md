# 0.7.1
- «Продолжить чтение»: убран блюр боковых карточек; свечение на конце прогресс-бара — мягкое овальное, без резких краёв.
- «Полки»: каждая полка — секция с названием, числом книг и стрелкой; обложки листаются горизонтально и стоят на цветной стеклянной планке, цвет которой берётся из обложек полки. Тап по заголовку — открыть полку, долгое нажатие — действия с полкой.
