# Полка 1.2.63

- Обложки: новый вид «твёрдая книга на столе» (Т2+) — матовая поверхность, мягкий корешок, острые правые углы, тень с контактной линией и падающей тенью, передающей толщину.
- Сетка библиотеки: при зажатии и перетаскивании книги обложка больше не моргает — поднятая карточка непрозрачна с первого кадра, плавно появляется и исчезает только тень подъёма.
