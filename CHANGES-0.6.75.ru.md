# 0.6.75

- Быстрое открытие книг:
  - Текст книги раскладывается по главам в отдельную копию; при открытии читается только оглавление и текущая глава (не вся книга). Копия строится один раз, база остаётся главной.
  - Картинки книги грузятся только когда нужны странице.
  - Страница, на которой остановились, показывается сразу после разбора главы; разбивка всей главы на страницы досчитывается в фоне.
  - При закрытии запоминается картинка последней страницы; при следующем открытии (те же настройки) она видна сразу, живой текст подменяет её незаметно.
  - Карточка книги больше не разбирает весь текст ради статистики.
