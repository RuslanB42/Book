# Полка 1.1.0

- Шрифты: во всём интерфейсе пара Piazzolla (заголовки, названия книг, большие цифры статистики) + Geologica (всё остальное). Текст книги в читалке — прежними шрифтами.
- Статистика, серия: при раскрытии календаря огонёк приподнимается и встаёт целиком, без прямого среза снизу; его свечение мягко уходит на календарь.
- Время чтения: подробности по дню — долгим нажатием (простое касание ничего не открывает), с анимацией появления; удерживая, можно вести пальцем по дням — подсказка плавно переезжает; закрывается касанием в любом другом месте или по графику. Свечение столбика больше не обрезается по краям.
