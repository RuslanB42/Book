# 1.0.2
- Статистика переработана по замечаниям: огонёк больше не налезает на текст и не вылезает (у него своё место), цвета насыщеннее (огонёк без белёсого налёта, столбики ярко-фиолетовые, свечение выбранного дня мягкое и не обрезается квадратом, низкие столбики видны); карточки и фон темнее и чётче; обложки «прочитано» — ровный кластер по центру, орбиты не вылезают за карточку; корешки в стопке цели всегда цветные; при прокрутке ничего не заходит под строку состояния; цифры при подсчёте не двигают соседние надписи.
- Календарь серии адаптирован: тонкий разделитель, стеклянные клетки, огонёк мягко растворяется при раскрытии.
- «Все книги» — отдельная страница: годы, число за год, список по месяцам (обложка, название, автор, дата, медаль оценки); въезжает справа на пружине.
