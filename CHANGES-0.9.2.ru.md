# 0.9.2
- Полки, liquid glass (Android 13+): искажение считается видеокартой каждый кадр прямо по живому ряду обложек — без снимков. Ничего не отстаёт, не мигает и не «обновляется»: прокрутка, нажатия, загрузка обложек, улетающая книга — всё видно сквозь стекло сразу.
- Обложка, летящая в карточку книги и обратно, над своей полкой рисуется внутри того же живого слоя — проходит под стеклом, искажаясь вместе с остальными книгами.
