# 2.2.9

- Комиксы: в шторке «Страницы» миниатюры наконец загружаются, рамка текущей страницы больше не обрезана. Шторки поверх комикса не показывают системную строку.
- Панели сверху и снизу больше не висят плашками: это мягкая тень цвета фона, как на макете.
- Касание по карточке соседней страницы перелистывает её с прокруткой, дальней — с мягким проявлением, без рывка. Текущая карточка больше не дёргается при нажатии.
