# Polka Native 0.6.30 — статистика по лекалам плашек «Серия» и «Скорость»

Все плашки страницы сделаны по одному шаблону с вашими образцами:
- плитка-иконка с цветом плашки и тихий заголовок;
- крупное число и серая подпись;
- тонкая шкала со вторичными подписями;
- мягкая широкая тень под плашкой: она «парит» над страницей (в тёмной теме плюс тонкая светлая кромка).

**Дни подряд.** Большой огонёк с числом; заголовок со склонением («день / дня / дней подряд»); подпись («Огонёк загорится после 10 минут чтения за день» / «Ещё N минут сегодня…» / «Сегодня цель достигнута»); строка «Сегодня — X из N мин» и тонкий прогресс с градиентом; семь кружков недели: сегодня обведено кольцом, дни с выполненной целью залиты янтарным с галочкой, частичное чтение отмечено точкой.

**Скорость.** Плитка с молнией, прочерк и подпись «посчитаем после пары минут чтения» (или число и «слов в минуту»); градиентная шкала 0 — «ср. 200» — 400+ с отметкой на 200; при наличии данных на шкале появляется ползунок со значением (плавно выезжает при первом показе).

**Цель на год, Прочитано книг, Время чтения, Любимый автор** — в том же стиле: каждая со своей плиткой-иконкой и цветом. Годовая цель — крупное «N из M» и шкала прогресса с отметкой «по плану»; «Время чтения» — столбики акцентного цвета; «Любимый автор» — обложки на мягкой плашке. Плашки идут в одну колонку.

Содержание и поведение (период, цель, редактирование, календарь) без изменений.
