# 0.6.63

- Перелистывание (тот же рендер со сгибом): поднятый край листа отбрасывает мягкую тень на страницу, сильнее в середине поворота.
- После отпускания пальца лист продолжает движение с той же скоростью; по тапу — ровный «ручной» поворот 0,52 с.
- Быстродействие: страница, которая только что пришла, переиспользуется как исходник следующего жеста — без захвата снимка в момент касания.
