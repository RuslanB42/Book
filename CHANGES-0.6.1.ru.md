# Полка Native 0.6.1 — стеклянные полки

Узкое исправление отрисовки полок; остальные различия переноса не объявляются устранёнными.

- Убран перенос прозрачности блика на первый, верхний левый болт. Каждый крепёж рисуется независимым Paint, с одинаковой непрозрачностью металлических слоёв. Угол меняется только у крестового шлица, не у освещения всей головки.
- Вместо несимметричного box-blur H/V/H применяется одинаковое гауссово размытие по обеим осям, sigma 3 CSS px с учётом масштаба.
- Размытая копия обложек сохраняет прозрачность; цвет усредняется с учётом alpha. Фон полки больше не попадает под brightness. Насыщенность 1.12, яркость .82/1.05 и белая тонировка .055/.4 соответствуют исходнику.
- Восстановлены два исходных слоя тени обложки и параметры тени стекла; копия обложки для frost содержит те же тени.
- Размытые обложки отсечены внутри рамки стекла, поэтому рамка не окрашивается книгой. Убраны чёрные выступы теней в правых углах обложек; тени не обрезаются контейнером ячейки.
- Толщина и отступ рамки учитывают плотность экрана, а не половину физического пикселя. Уточнены шайба, грани и блик болтов, координаты крепежа.
- Размытие вычисляется в фоне и кешируется по обложкам/размеру. Нового размытия на каждом кадре прокрутки нет. Неиспользованные фоновые результаты освобождаются.

Проверки: профиль гауссова размытия по обеим осям, прозрачные края без чёрного ореола, яркость всех четырёх болтов, шесть отдельных изображений — пустая/одна/три книги в двух темах — рядом с отрисовкой исходного HTML.

Сборка с прежней подписью, versionCode 7; схема SQLite 1. Обновлять поверх предыдущей версии. Перед обновлением сохранить внешнюю .polka; не удалять приложение и не очищать данные.

Нет замеров GPU/FPS на физическом S22. Это исправление конкретной отрисовки, не подтверждение полного паритета приложения.
