# 0.8.4
- Полки, стекло: середина больше не перерисовывает книги — они видны напрямую, чётко и без сдвига. Преломление только на верхней и нижней кромке, плавной сеткой без ступенек; кромки снимаются тонкими полосками только при смене обложек или уходе далеко в сторону.
- Плавность: каждая полка больше не перерисовывает все обложки 13 раз за кадр; обложка при загрузке только перерисовывается, без замены вида и перестройки ряда; остальные обложки догружаются пачками в покое, а не во время листания.
