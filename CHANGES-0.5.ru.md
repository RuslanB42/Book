# Полка Native 0.5 — переработка переходов, не заявление о полном паритете

## Раскрытие книги
- Вместо снимка читалки внутрь перехода помещается тот же живой нативный View, который остается на экране после завершения. Нет подмены страницы последним кадром.
- Исходная временная шкала 1680 мс: подъем .27, промежуточная поза .37, раскрытие .66, разворот обложки до −166°, увеличение страницы по 36 исходным отсчетам.
- Камера 1700 dp, исходный центр перспективы 50%/48%, шарнир обложки слева. Однородный масштаб глифов через обратное преобразование страницы.
- Панели чтения появляются только между .82 и .98. Физические поверхности исчезают по исходным 24 отсчетам, а не вместе с читалкой.
- Убраны снимок библиотеки под переходом и декоративная светлая окантовка. Возвращены переплет в цвет книги, утопленный бумажный блок и тень задней крышки.
- Повторное открытие во время загрузки блокируется. Завершение/прерывание возвращает исходный экран чтения; время анимации не добавляется к чтению.

## Раскрытие рекомендации
- Один управляемый счетчик времени вместо независимых некоординированных анимаций.
- Исходные 620 мс открытия / 520 мс возврата; обложка min(170 dp, 44% ширины), единый масштаб, собственное появление подсветки и кнопки назад.
- Задержки 150 + min(i,6)×45 мс назначаются смысловым блокам (название, автор, факты, секции), а не пустым View-отступам.
- При раннем закрытии сначала завершается входной переход, затем выполняется возврат — как в исходнике. Отмена не оставляет скрытую карточку в колоде.
- Убрана системная анимация окна, которая накладывалась поверх пользовательского перехода. Добавлены системные отступы для API 35.

## Другие изменения этой итерации
- Полки и сетка библиотеки создают только карточки около видимой области, а не всю библиотеку сразу.
- Размытие полок вынесено из потока интерфейса. Типографика обложек кешируется; уточнены окончательные CSS-слои корешка и балансировка заголовка.
- Сопоставление библиотеки с каталогом использует индекс вместо повторного полного перебора каталога.
- Цитаты сгруппированы стопками по книгам; добавлены переход в группу и возврат. Отмена анимации больше не вызывает действие завершения (например, удаление).
- Уточнены исходные длительности переходов вкладок, полок, сегментов и индикатора навигации.

## Границы результата
Это не подтверждение абсолютного визуального/функционального паритета всего приложения и не доказательство устранения всех ANR. Проверки выполнены на JVM/Robolectric с нативной графикой и в локальном Chromium, не на физическом Samsung S22. Записанные покадровые последовательности не измеряют реальную частоту кадров Android/GPU.

Остаются необходимыми профилирование и длительное использование на S22/One UI, большие реальные EPUB (особенно единые длинные главы), фон/возврат, все комбинации жестов, раскладки и масштабы шрифтов. Текущая разметка/пагинация главы еще выполняется в потоке UI; для очень длинных глав риск задержек не снят. Устранены конкретные тяжелые операции и ошибки, а не доказаны все возможные причины ANR.

Схема Room остается 1, package прежний. Перед обновлением сохранить внешнюю .polka; не удалять прежнее приложение и не очищать данные.
