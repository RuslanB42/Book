# Полка Native 0.6.2 — читалка, полноэкранный режим, блокнот

## Перелистывание
- Входящая страница заранее вынесена за экран. Снимок исходящей остаётся до PreDraw, в котором TextView уже имеет раскладку нового текста. Убран показ промежуточной старой раскладки.
- Снимок не recycle-ится синхронно с удалением ImageView: аппаратный render thread может ещё использовать его display list. Объект освобождается после завершения использования платформой.
- Повторное нажатие во время перехода не срывает текущую анимацию. Продолжительность 520 мс в главе и 560 мс между главами, cubic-bezier(.25,.1,.25,1).
- Смена страницы внутри главы не запускает повторный разбор и пагинацию всей главы. Пятисекундное сохранение позиции остаётся фоновым.

## Samsung S22 и системные области
- Читалка включает immersive mode на API 26–35. Статусная строка и системная навигация скрываются; системный свайп может временно показать их — это штатное безопасное поведение Android.
- Включён layout под системными областями, разрешено использование экрана с вырезом. Вырез камеры, жестовая область и клавиатура учитываются отдельно внутри читалки, а не серыми полосами вокруг неё.
- Цвет фона продолжается до границ окна; отключена контрастная заливка системной навигации. При выходе системные панели и отступы библиотеки восстанавливаются.
- Режим повторно применяется после возврата в приложение/закрытия панели. Нет обещания скрыть аппаратный вырез или запретить системные жесты.

## Интерфейс и блокнот
- Нижняя панель: название главы слева, оставшиеся страницы справа, исходная геометрия ползунка 4/24 dp, равномерно расположенные инструменты; значок оглавления с блокнотом из исходного SVG. Номер страницы находится под панелью, не поверх её кнопок.
- Навигация «Оглавление / Блокнот / Поиск» в высокой панели, как в исходном HTML. Блокнот доступен через нижнюю кнопку и через «Ещё → Блокнот: цитаты и мысли».
- Фильтры «Все / Цитаты / Заметки / Закладки», счётчики, поиск в блокноте, цитаты со связанными мыслями. Добавление/редактирование мыслей, копирование, удаление и переход к тексту не закрывают саму книгу.
- Поиск по тексту книги выполняется фоново; запоздалые ответы не заменяют более новый запрос.
- Меню книги приведено к четырём исходным разделам; оформление и редактор главы остаются в нижней панели.

## Проверки и ограничения
Пять новых регрессионных сценариев: порядок кадров и повторный тап, cutout/жесты/IME API35, immersive API28, фильтрация/копирование/переход к цитате, три вкладки и поиск. Контрольные PNG и HTML-эталон — qa/reader-0.6.2; области экрана — qa/s22/reader-cutout-*.

Это не доказательство полного попиксельного паритета: растеризация текста, переносы, прозрачность панелей и некоторые детали редакторов ещё отличаются. Нет измерений FPS/ANR на физическом Samsung S22, проверки One UI или установки поверх реальной пользовательской библиотеки. Синтетические кадры теста не являются записью плавности телефона.

Версия 0.6.2, versionCode 8; applicationId и сертификат прежние, схема SQLite 1. Перед обновлением сохранить внешнюю .polka. Устанавливать поверх, не удаляя приложение и не очищая данные.
