# Полка 1.2.73

- «Огонёк»: на капсуле «жар» больше не мелькают полосы — один медленный мягкий отблеск, который проявляется и гаснет внутри заливки (на малых минутах его нет).
- Плашки «Огонёк» и «Цель» в настройках: свечение теперь действительно видно (раньше оно рисовалось почти прозрачным).
- «Цель»: вехи на дороге скользят плавно без раскачки; новые выезжают из флажка, лишние уезжают в него и гаснут. Цифры при быстрой прокрутке ленты не «прокручиваются» друг в друга — катятся только при спокойном изменении. То же для цифр огонька.
