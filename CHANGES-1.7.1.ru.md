# Листай 1.7.1

- Плашка при выделении — пять иконок: цитата, заметка, перевод, словарь, копировать (у сохранённой цитаты — её цвет и корзина).
- Перевод: прямо на телефоне (Google ML Kit), язык определяется сам; языковой пакет скачивается один раз, дальше работает без интернета. Языки можно поменять местами.
- Словарь: русский и английский из Викисловаря, без интернета — база скачивается один раз. Начальная форма с ударением, часть речи, толкования с примерами, синонимы; у английских слов — транскрипция и перевод. Озвучка голосом телефона. «Копировать» и «В заметку».
- В настройках — раздел «О приложении» с источниками.
