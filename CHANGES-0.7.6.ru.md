# 0.7.6
- «Продолжить чтение»: название в одну строку с многоточием, автор сразу под ним; фон карточки — цвета обложки, плавно переходящие в обычный серый.
- Полки: вкладка открывается без рывка — сначала строятся только видимые обложки, остальные догружаются при листании; стекло полок рисуется один раз на все ряды.
- Оценки в годовой цели: эмалевые медали с золотой оправой (1–2 монета, 3 щит, 4–5 шестиугольник) вместо плашки со звездой.
