# Polka Native 0.6.23

Исправлена прямая нижняя граница свечения и скачок его формы в конце открытия «О книге».

- Ранее View со свечением имел высоту только блока обложки (234 dp), хотя размытый растр выступал ниже. При частичной прозрачности ограниченный альфа-слой обрезал эту часть; при полной прозрачности 1 обрезка исчезала. Теперь реальные границы View включают всю полутень с прозрачным запасом.
- Прозрачность применяется в Paint растрового изображения через onSetAlpha, без неявного ограниченного альфа-слоя View. Геометрия свечения одинакова на промежуточных и финальном кадрах.
- Учтены смещение и центр нового расширенного слоя при совместном движении с обложкой. Такое же исправление применено к подробностям рекомендаций.
- Появление по-прежнему связано с финальным приземлением обложки. Огибающая яркости немного растянута и использует плавное начало/окончание без резкой смены скорости.
- Цвета по-прежнему берутся из размытого изображения обложки. Затухание при переходе в читалку, интерактивный свайп и анимированное раскрытие блоков сохранены.

Проверки: яркие светлые растровые обложки, границы всего растра внутри View, равенство ограниченного/неограниченного слоя, покадровая разница 99% → 100% прозрачности, приземление и обратный жест; полный регрессионный прогон. Это нативная графика Robolectric с моделированием ограниченного слоя, не проверка на физическом S22/GPU.

Версия базы не меняется. Устанавливать поверх предыдущей версии, не удаляя приложение. Рекомендуется резервная копия .polka.
